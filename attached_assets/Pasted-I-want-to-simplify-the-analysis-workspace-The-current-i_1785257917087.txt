I want to simplify the analysis workspace.

The current interface repeats the same information in multiple places and feels more complex than necessary.

The goal is to reduce duplication and improve clarity.

========================================
1. Remove duplicated information
========================================

The dataset quality currently appears in multiple places:

- Dataset sidebar
- Summary Card
- Overview
- Insights

This is too repetitive.

Keep the detailed dataset quality only inside the Summary Card.

In the dataset sidebar, keep only a small quality badge/progress indicator.

Do not repeat the same quality information elsewhere.

========================================
2. Rethink the Insights tab
========================================

The current Insights tab mostly repeats technical checks such as:

- No missing values
- No duplicate rows
- Numeric columns detected

These are not meaningful insights for users.

Instead, Insights should provide practical recommendations or useful observations.

Examples:

- This dataset is ready for dashboard creation.
- A date column was detected. Time-series analysis is recommended.
- Most columns are numeric, making the dataset suitable for statistical analysis.
- Consider creating category-based charts.
- This dataset appears clean and ready for visualization.

If there are no meaningful insights, do not generate filler content.

Quality checks should stay in the Summary section instead.

========================================
3. Keep each piece of information in one place
========================================

Follow this rule throughout the workspace:

One piece of information = One location.

Avoid repeating the same metric in multiple sections.

========================================
4. Make the workspace feel simpler
========================================

The objective is not to add more features.

The objective is to make users understand their dataset faster with less scrolling and less repeated information.

The interface should feel calm, focused, and professional.
