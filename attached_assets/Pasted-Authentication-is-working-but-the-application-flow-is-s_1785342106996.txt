Authentication is working, but the application flow is still incomplete. Complete the navigation and project workflow before adding any new features.

1. Fix Dashboard workflow
The "New Project" button must never redirect to the public landing page.
It should open the Workspace directly.
Uploading a file from the dashboard should create a project owned by the logged-in user.
The project must be saved and appear in "Recent Projects".
Clicking a recent project should reopen it.
2. Add global navigation

The authenticated experience should always provide navigation.

Requirements:

Add a persistent top navigation bar.
Include:
Dashboard
Workspace
Relationship Manager
Highlight the current page.
Users must always be able to return to the Dashboard with one click.

Never trap the user inside the Workspace or Relationship Manager.

3. Add Back navigation

Every page except the Dashboard should have a Back button.

Examples:

Workspace
← Dashboard

Relationship Manager
← Workspace

The Back button should return the user to the previous application page, not the browser history.

4. Keep users inside the authenticated experience

Once a user signs in:

Never redirect them to the public landing page.
The landing page should only be shown to guests.
Signed-in users should move only between Dashboard, Workspace, and Relationship Manager.
5. Safe deletion (Undo)

When a user deletes something, do not permanently delete it immediately.

Instead:

Show a toast notification:
"Dataset deleted."
Include an "Undo" button.
Allow Undo for about 5–10 seconds.
If Undo is clicked, restore the deleted item exactly as it was.
After the timeout, perform the permanent deletion.

This behavior should be used for:

Dataset deletion
Project deletion
Relationship deletion
6. Confirmation before destructive actions

Before permanently deleting anything, show a confirmation dialog.

Examples:

Delete Dataset?

"This action cannot be undone after the Undo period expires."

Buttons:

Cancel

Delete

Do not redesign the interface.

Focus only on completing the authenticated workflow, navigation, persistence, and safe deletion.
